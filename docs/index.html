GENLAYER AGENT LICENSE ADMISSION

LicenseCourt

Give an AI agent bounded permission to use a content, API, or model asset only after GenLayer validators assess the committed license evidence.

A permission is not a dashboard label. The registered agent, scope, terms snapshot, expiry, challenge state, and remaining uses are enforced in the contract.

Live contract

Set the deployed Studio or Bradbury address, then connect a compatible wallet.

1. Register

Commit license terms

The owner locks both parties, the real agent executor, exact asset/terms locations, two evidence sources, scope, use cap and expiry.

2. Assess

Request a consensus verdict

Validators retrieve and compare the committed license material. Unavailable or conflicting sources become inconclusive, never an approval.

3. Challenge

Freeze an approval

4. Consume

Use the approved license

Only the registered agent can consume an approved and unexpired record. Every use receives a one-time receipt.

5. Read and recover

Finalized contract state

What validators bind

  1. The license ID is derived from one canonical license object and one non-reusable nonce.
  2. Assessment persists the license hash plus full terms, asset and evidence-bundle SHA-256 snapshot commitments.
  3. Challenge eligibility is limited to named parties and already committed source identities; the contract freezes consumption while a challenge is active.
  4. The UI waits for consensus finality, then reads the exact ID from the selected contract rather than treating a submitted wallet transaction as success.
