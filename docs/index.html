GENLAYER AGENT LICENSE ADMISSION

LicenseCourt

Give an AI agent bounded permission to use a content, API, or model asset only after GenLayer validators assess the committed license evidence.

Every contract action uses the repository-defined GenLayer adapter. It waits for consensus finality, then re-reads final contract state before the UI reports success.

Live contract

Set the deployed Studio address, then connect a GenLayer-compatible wallet.

1. Register

Commit license terms

The owner locks both parties, agent executor, exact terms, independent evidence, scope, use cap and expiry.

2. Assess

Request a consensus verdict

Validators retrieve and compare committed license material. Unavailable or conflicting sources become inconclusive, never approval.

3. Challenge

Freeze an approval

4. Consume

Use the approved license

Only the registered agent can consume an approved and unexpired record. Every use receives a one-time receipt.

5. Read and recover

Finalized contract state

What validators bind

  1. The license ID derives from a canonical license object and non-reusable nonce.
  2. Assessment persists license, terms, asset and evidence-bundle SHA-256 snapshot commitments.
  3. The page uses GenLayerJS reads and writes through genlayer-adapter.js; it does not use ethers or ordinary EVM calls.
  4. Each UI state change requires successful GenLayer consensus finality and a final-state readback of the exact license ID.
